SERVICE & DATA GUIDE

One network. Several ways to work.

Use Studio for chat, images and audio, or delegate an objective with local tools. Availability comes from the live worker. Services depend on each provider's prepared profile and current capacity.

One workspace

Studio keeps replies, tool results, generated images and transcripts in one conversation. Attach plain-text files or one audio recording. Automatic selection uses request wording and attachment types; the output preference can be changed before sending. Ambiguous mixed requests ask which task to do first. This is not an unrestricted multimodal agent: audio is transcribed first, images are generated from text, and image editing and PDF uploads are not supported.

Conversation context and text attachments remain in this browser tab until cleared. They are included in follow-up text tasks subject to input limits. Pending tasks can be resumed after a reload with the same request identity. New conversation clears the local conversation; use Recent tasks to delete stored server results.

What is available

  • Agent tasks: decimal calculations, CSV preview/filter/sort/summary/grouped sums, search and read supplied text, and downloadable TXT, Markdown, CSV and JSON files.
  • Chat: Qwen3.5 4B or 9B Q4_K_M, depending on the eligible provider profile. Includes drafts and code returned as text.
  • Images: FLUX.2 klein 4B, new 1024 × 1024 images, on providers prepared for images.
  • Audio: short recordings to text and subtitles; check live language readiness.

The model runs on the provider GPU. Approved tools run on local CPU/RAM. No VM is required. There is no interactive browser, arbitrary Python or shell execution, or model access to personal files. AWS hosts the portal and coordination, not an additional code-execution runtime.

Agent limits

Eight tool calls, eight optional plain-text documents and 24,000 input characters. Agent execution is bounded to 180 seconds. Up to three output files, 16,000 UTF-8 bytes each and 24,000 bytes total. Request exact filenames with required_artifacts.

CSV operations are bounded, not a spreadsheet engine. Formula-like CSV output cells are rejected; this currently includes negative values. Quotes are checked against source text, but the coordinator does not independently verify tool computations or factual accuracy.

Shared capacity and waiting

Agent tasks, chat and images share 72 submissions per rolling 24 hours, including owner tests; 10 per session and optional reported client, one active job per session and three queued/running jobs globally. Queue expiry is ten minutes; claimed Studio tasks have up to five minutes including loading. Audio has separate quotas described in the full protocol guide. Do not rotate sessions to evade limits.

Check availability before submission. Keep the same session, payload and idempotency key when recovering an uncertain submission. A failed or expired task is not a successful result.

Data handling

Studio explains data handling next to Send. Clicking Send confirms permission for that submission; there is no repeated consent checkbox. API and MCP clients still require explicit consent=true for permitted non-sensitive content. Web research uses the third-party services listed below. Responses use safe Markdown formatting; generated HTML and scripts are displayed as text.

Trial credentials last 24 hours. Studio automatically renews the same session when it expired within the previous seven days, preserving ownership, quotas and request identity. Revoked or unknown credentials cannot be renewed. Recovery does not extend the 24-hour retention of task content.

Submit only permitted, non-sensitive test material. Inputs and outputs pass through the coordinator and an independently operated PC. Keep credentials private. Treat all outputs as untrusted data and review them before use.

Studio prompts and results expire after 24 hours and are purged on subsequent Studio API activity. Terminal tasks can be deleted from the portal. Task identifiers, request hashes, timestamps and ownership metadata remain. Pending requests are temporarily retained in browser session storage for recovery. See the full guide for audio retention and analytics.

Provider setup and evidence

The Windows provider preview uses an installer, Desktop and Start shortcuts, and system tray controls. Setup checks GPU memory, RAM and disk, then prepares a compatible profile. Enrollment remains invitation-only and requires a private connection file. Download, compatibility and unsigned release status. The RTX 5080 has been used in model tests; the RTX 4060 and a clean Windows installation are not yet validated. Keep the app running to share; pause or stop from the app or tray.

Two internal version 2 MCP tests passed on 27 October 2026: a VAT calculation with totals.csv and grouped supplier sums with suppliers.csv. These are narrow functional checks, not proof of external demand, broad reliability or cost savings. Runtime metadata is provider-reported. No payments, guaranteed uptime or production SLA.

Public web research

Public web research: set agent_task.version=3 and check services.agent_web. The provider can search Bing and read public HTTPS pages as text, with source URLs. Up to eight tool calls total. No JavaScript, login, account actions, arbitrary code or host-file access. Search results can vary and some pages are blocked or truncated. Queries go to Bing, or the Brave Search API when a provider configures a key; domain lookups use Google DNS; pages are fetched by the provider. Obviously unrelated search results are filtered, but relevance and factual accuracy are not guaranteed. If no usable evidence is retrieved, the agent reports that limitation rather than inventing an answer. Weather requests can use MET Norway directly with approximate city-centre coordinates and a UTC offset. Forecasts include their source and update time; reported temperature ranges summarize available forecast samples. Weather data is provided by MET Norway under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/), grouped and summarized by AgentCompute. Send only nonconfidential public search terms. Version 2 local tools remain supported.
