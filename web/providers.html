Getting started

Install. Set up. Share.

01 / INSTALL

Install AgentCompute

Run the installer and approve the Windows administrator prompt. The default folder is C:\Program Files\AgentCompute.

02 / SET UP

Set up this computer

Open the app and follow setup. Supply your private connection file. AgentCompute checks the available GPU memory, RAM and disk, then downloads and tests a compatible model. An NVIDIA driver and official Ollama are required.

03 / SHARE

Start when you are ready

Click Start sharing and allow approved tasks. Pause or stop anytime. Closing the window keeps the app in the system tray; Exit stops sharing and quits.

Compatibility

Will it work on my PC?

NVIDIA GPU · Windows x64

Setup selects one GPU and a model profile based on available VRAM, RAM and disk. Current profiles target cards with at least 8 GB VRAM; resource checks and GPU tests must pass.

The RTX 5080 has been used for model tests. An RTX 4060 and a clean Windows installation have not yet been validated. Separate GPUs are not pooled.

Your files stay separate

The app installs in Program Files. Models and personal settings are stored under your Windows account. Uninstalling the app retains these files.

Private connection files are supplied separately and are never bundled in this public download.

Provider questions.

What runs on my computer?

The GPU runs AI models. Approved tools also use CPU, RAM and internet access for calculations, supplied files and public web research. Available services depend on the prepared profile. This preview does not execute arbitrary customer code.

Do I need PowerShell or a virtual machine?

The desktop app controls the provider. Keep the app running in its window or system tray. These tools do not require Docker, a VM or Hyper-V.

Where do I get a connection file?

Enrollment is arranged with the pilot operator. Each provider needs its own private connection file. Public self-service enrollment is not available yet.

Can I game while sharing?

Pause sharing from the app or AC tray menu before starting demanding GPU applications. Resume when the computer is available.

How much will I earn?

This experimental pilot has no paid rewards. Pricing, payments and verified cost savings remain under development.
